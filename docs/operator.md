# Operator foundation

This delivery provides a deterministic dispatcher, not AI-backed natural-language reasoning. Supported:
- current configuration/languages;
- agent connection status;
- contribution/ready summaries;
- persisted discovery/scan summaries;
- ranking reasons when a full repository name is supplied;
- exactly Add Rust, Include Rust or I want to contribute to Rust as a proposal template.

Unsupported multi-setting requests do not partially apply changes. The editor supports full structured proposals. No proposal is automatically applied. The user reviews it under Configuration.
A later AI adapter may choose allowlisted domain tools, but will never receive unrestricted shell access, bypass execution approval or submit a PR automatically.
