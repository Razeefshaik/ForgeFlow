# Codex effort

A separate heuristic maps relevant file count, concurrency and integration-test needs to VERY_LOW through VERY_HIGH. It returns iteration/file ranges, context-size description, test complexity, confidence and explanations.
Confidence is a conservative fixed heuristic (40% when scope unknown, 70% when scope described), not an empirically calibrated probability. Demo inputs are illustrative.
Plan allowance percentage is null because no supported source is connected. Actual execution metrics are unavailable until a runner exists. Future history will calibrate estimates against observed completed work.
Effort must never alter opportunity quality, merge probability or canonical ordering.
